# Zulqarnain Sarwar | Personal Portfolio

A responsive personal portfolio for opportunities in IT support, document control, project administration, and administrative or data operations. The site is built with HTML, CSS, and vanilla JavaScript for GitHub Pages.

## Files

```text
.
├── index.html
├── styles.css

├── README.md
└── cv/
    ├── Zulqarnain_IT_Support_Technical_CV.docx
    ├── Zulqarnain_Document_CV.docx
    └── Zulqarnain_Admin_Assistant_CV(1).docx
```

## Preview locally

1. Extract the ZIP and open the project folder.
2. Open `index.html` in a browser. No build tools or package manager are needed.
3. For a local server, run `python -m http.server 8000` from the project folder, then visit `http://localhost:8000`.

## Publish with GitHub Pages

Repository: `https://github.com/Zzulqarnainn/zulqarnain.github.io`

1. Extract the ZIP.
2. Open the repository and select the `main` branch.
3. Upload the contents of the `zulqarnain-portfolio` folder to the repository root. The `index.html`, `styles.css`, `script.js`, `README.md`, and `cv` folder should appear directly in the root.
4. Commit the changes.
5. In **Settings**, open **Pages** and select the `main` branch with the repository root as the publishing folder.
6. Wait for deployment, then visit `https://zzulqarnainn.github.io/`.

CV download links use relative paths, so they work from the repository root.

## Dependencies

The site does not use a JavaScript framework or backend. Google Fonts are loaded when available, with local system fonts as fallbacks. Email and phone links open the visitor's email app or phone handler. There is no contact form.
